# Security Policy

## Supported version
The current `main` branch is supported.

## Reporting
If you find a security or privacy issue, report it through GitHub's private vulnerability reporting feature when available. Do not publish secrets or sensitive visitor information in a public issue.

## Scope
This is a static portfolio with no authentication, database, server-side code, analytics or intentional collection of visitor data. Hosting-layer TLS, response headers, DNS and platform configuration are outside this repository.

External links are intentionally opened with `noopener noreferrer`. Contributions must not add credentials, trackers or unsafe dynamic HTML handling.
