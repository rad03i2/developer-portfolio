# Contributing

Thanks for helping improve Developer Portfolio.

1. Keep the site dependency-free unless a new dependency has a clear, documented benefit.
2. Preserve English/Arabic behavior, keyboard accessibility, responsive layout and privacy-friendly defaults.
3. Do not add private contact information, credentials, trackers or fabricated project claims.
4. Run `node --check script.js` and `node --test tests/portfolio.test.mjs` before proposing changes.
5. Keep commits focused and explain user-visible changes in the pull request.

Project data should link only to real projects owned or maintained by the author.
